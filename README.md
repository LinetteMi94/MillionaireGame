# MillionaireGame

Игра-викторина на C# и WinForms.

Проект создан в учебных целях для практики разработки приложений с графическим интерфейсом.

## Технологии

- C#
- .NET 9
- Windows Forms
- JSON

## Возможности

- Главное меню игры
- Игровое окно
- Вопросы с вариантами ответов

## В планах

- Добавить банк вопросов
- Реализовать уровни выигрыша
- Добавить подсказки
- Реализовать обработку правильных и неправильных ответов
